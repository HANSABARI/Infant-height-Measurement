# H-ALIGN AI Server API

## Purpose

This server is the inference-only component for `jaram-height-web`.
It receives a normalized image from the web worker, estimates height with card
segmentation and RTMPose, and returns a measurement result. It does not access
Supabase, retain uploaded images, receive a user or baby identifier, or manage
measurement history.

## Endpoint

```http
POST /api/v1/measure
Content-Type: multipart/form-data
Authorization: Bearer <shared-ai-api-key>
X-Measurement-Id: <uuid>
```

### Configuration

Set the same secret in both systems:

```bash
# h-align-server
export H_ALIGN_AI_API_KEY='<shared-ai-api-key>'

# jaram-height-web Supabase Edge Function secret
# AI_API_KEY='<shared-ai-api-key>'
```

`H_ALIGN_AI_API_KEY` is required. Without it, the AI endpoint returns `503`
before loading an image into the inference pipeline.

### Request

| Part | Type | Required | Description |
|---|---|---:|---|
| `file` | image file | yes | Normalized JPEG or PNG generated by the web backend |
| `Authorization` | header | yes | `Bearer` shared AI API key |
| `X-Measurement-Id` | header | yes | The measurement attempt identifier generated by the web backend |

The response echoes `X-Measurement-Id` in `measurementId` exactly.

## Success response

```json
{
  "measurementId": "7d474c14-6208-4380-8c7f-e9609da83f98",
  "status": "SUCCESS",
  "result": {
    "estimatedHeightCm": 64.2,
    "heightRangeCm": null,
    "confidence": null,
    "quality": null,
    "modelVersion": "h-align-has-rtmpose-head-top-v1",
    "warnings": [],
    "measuredAt": "2026-08-23T12:30:00Z"
  },
  "error": null
}
```

Only the public measurement result is returned. Card masks, bounding boxes,
keypoints, segment lengths, and debug artifact paths remain inside the AI
server.

## Retry response

Expected, user-recoverable image failures use HTTP `200` with `RETRY`.

```json
{
  "measurementId": "7d474c14-6208-4380-8c7f-e9609da83f98",
  "status": "RETRY",
  "result": null,
  "error": {
    "code": "CARD_NOT_FOUND",
    "message": "참조 카드를 찾지 못했습니다. 카드가 전체 보이도록 다시 촬영해주세요."
  }
}
```

The server currently returns `RETRY` for `INVALID_IMAGE`, `CARD_NOT_FOUND`,
`PERSON_NOT_FOUND`, `BODY_CROPPED`, `BAD_POSE`, and `LOW_CONFIDENCE`.

## Terminal failure response

Deterministic internal failures, such as a missing head-top checkpoint, use
HTTP `200` with `FAILED`. This lets the remote AI client parse the terminal
result rather than treating it as a transient outage.

```json
{
  "measurementId": "7d474c14-6208-4380-8c7f-e9609da83f98",
  "status": "FAILED",
  "result": null,
  "error": {
    "code": "INFERENCE_FAILED",
    "message": "AI 추론을 완료하지 못했습니다."
  }
}
```

`heightRangeCm`, `confidence`, and `quality` are included as `null` until they
are calibrated against ground-truth measurement data. They must not be inferred
from raw detector scores or a fixed error margin.

Unexpected model runtime errors return HTTP `500` with no contract response
guarantee. Network failures, timeouts, and service overload must use HTTP
`429` or `5xx`; the Worker treats those as transient and retries them.

## Debug endpoint

```http
POST /api/v1/measure/debug
Content-Type: multipart/form-data
Authorization: Bearer <H_ALIGN_AI_API_KEY>
```

This local development endpoint writes a visualization into `debug_images/`.
It is disabled by default and returns `404`. Set
`H_ALIGN_DEBUG_API_ENABLED=1` to enable it; an enabled endpoint still requires
the same Bearer token as the main measurement endpoint.
The production Worker must call only `/api/v1/measure`.
