H-ALIGN 키 측정을 위한 AI 모델 추천입니다. 두 가지 핵심 태스크별로 정리합니다.

## 1. 참조 객체(카드) 인식

**목적**: 알려진 크기의 카드(신용카드 85.6×53.98mm 등)를 감지하여 px→cm 변환 비율 산출

| 모델 | 특징 | 추천도 |
|------|------|--------|
| **YOLOv8/v11** | 커스텀 학습 쉬움, 카드 바운딩박스 빠르게 검출, FastAPI 서빙에 최적 | ⭐⭐⭐⭐⭐ |
| OpenCV 컨투어 + 호모그래피 | 딥러닝 없이 사각형 검출 가능, 조명 민감 | ⭐⭐⭐ |

**실전 접근**: YOLOv8-nano로 카드 검출 모델을 학습시키거나, 아예 OpenCV로 사각형 컨투어를 찾아 4점 호모그래피로 실제 크기 매핑하는 게 가장 가볍습니다.

## 2. 아이 키 측정 (스켈레톤 기반 권장)

### 스켈레톤 방식 (더 정확)

| 모델 | 특징 | 추천도 |
|------|------|--------|
| **RTMPose (MMPose)** | SOTA급 정확도, 경량 모델 있음 (RTMPose-t/s), ONNX 변환 쉬움 | ⭐⭐⭐⭐⭐ |
| **MediaPipe Pose** | Google 제공, 33개 키포인트, Python API 간단, 정확도 준수 | ⭐⭐⭐⭐ |
| YOLOv8-Pose | 검출+포즈 원샷, 17개 키포인트(COCO), 속도 최고 | ⭐⭐⭐⭐ |
| ViTPose | Transformer 기반, 정확도 최상이나 무거움 | ⭐⭐⭐ |

### 바운딩박스 방식 (빠르지만 덜 정확)

| 모델 | 특징 |
|------|------|
| YOLOv8-det | person 클래스 bbox 높이로 추정, 자세에 따른 오차 큼 |

## 3. 추천 파이프라인

```
사진 입력
  ↓
[Stage 1] 카드 검출 (YOLOv8-nano 또는 OpenCV 컨투어)
  → 카드 bbox/4점 좌표 → px_per_cm 계산
  ↓
[Stage 2] 아이 포즈 추정 (RTMPose 또는 MediaPipe)
  → 머리 꼭대기(head_top) ~ 발바닥(ankle/heel) 키포인트
  → 픽셀 거리 계산
  ↓
[Stage 3] 키 산출
  height_cm = pixel_distance / px_per_cm
  confidence = f(카드 검출 신뢰도, 포즈 신뢰도, 자세 각도)
  ↓
범위값 반환: { min, max, confidence }
```

## 4. FastAPI 서빙 구성

```python
# 핵심 의존성
# pip install fastapi uvicorn ultralytics mediapipe opencv-python-headless

from fastapi import FastAPI, UploadFile
from ultralytics import YOLO
import mediapipe as mp
import cv2, numpy as np

app = FastAPI()

card_model = YOLO("card_detector.pt")       # 커스텀 학습된 카드 검출
pose = mp.solutions.pose.Pose(static_image_mode=True, model_complexity=2)

CARD_WIDTH_CM = 8.56  # 신용카드 가로

@app.post("/measure")
async def measure_height(file: UploadFile):
    img = cv2.imdecode(np.frombuffer(await file.read(), np.uint8), cv2.IMREAD_COLOR)
    
    # 1. 카드 검출 → px_per_cm
    card_results = card_model(img)
    card_bbox = card_results[0].boxes[0]  # 가장 신뢰도 높은 카드
    card_width_px = card_bbox.xyxy[0][2] - card_bbox.xyxy[0][0]
    px_per_cm = float(card_width_px) / CARD_WIDTH_CM
    
    # 2. 포즈 추정 → 키 픽셀
    results = pose.process(cv2.cvtColor(img, cv2.COLOR_BGR2RGB))
    landmarks = results.pose_landmarks.landmark
    head_y = landmarks[0].y * img.shape[0]      # nose (근사)
    heel_y = landmarks[29].y * img.shape[0]      # left heel
    height_px = abs(heel_y - head_y)
    
    # 3. 키 산출
    height_cm = height_px / px_per_cm
    margin = 0.35  # 오차 마진 cm
    
    return {
        "height_range": {"min": round(height_cm - margin, 1), 
                         "max": round(height_cm + margin, 1)},
        "confidence": round(float(card_bbox.conf[0]) * 0.5 + 0.5, 2),
        "method": "h-align"
    }
```

## 5. 정확도 올리기 위한 핵심 포인트

**카드 쪽**: 카드가 바닥에 평평하게 놓여 있어야 함 → 촬영 가이드에서 강조. 기울어진 카드는 호모그래피 보정 필요

**포즈 쪽**: 
- 머리 꼭대기는 COCO 키포인트에 없음 → 코(nose)에서 위로 보정 계수 적용 (약 +8~12cm 영아 기준)
- 아이가 누워있는 경우(영아) vs 서있는 경우(유아) 분기 처리 필요
- RTMPose는 `head_top` 키포인트를 직접 제공하는 WholeBody 모델이 있어서 더 유리

**최종 추천 조합**: **YOLOv8-nano(카드) + RTMPose-s(포즈)** — 정확도와 속도 균형이 가장 좋고, 둘 다 ONNX로 변환하면 GPU 없이도 FastAPI에서 충분히 서빙 가능합니다.
